# Smart Expense Splitter
A Java project developed to split shared expenses among friends.

## Features
* Add friend names
* Store expenses paid
* Calculate total expense
* Calculate average share
* Display who should pay or receive money

## Technologies Used
* Java

## Concepts Used
* Arrays
* Loops
* Conditions
* Scanner Class
* Basic OOP Concepts
